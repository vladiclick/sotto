# Security

Sotto needs the Microphone and Accessibility permissions and can type into
any app, so security reports are taken seriously.

Please report vulnerabilities privately through GitHub's
**Security → Report a vulnerability** on this repository, not in a public
issue. You'll get a reply within a few days.

Scope includes: anything that could make Sotto record outside a dictation,
send data off the device, type somewhere the user did not intend, or load a
model file that did not pass its checksum.
