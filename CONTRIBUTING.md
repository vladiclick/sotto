# Contributing to Sotto

Thanks for helping. Sotto is small on purpose: one job — dictation that is
private, fast and never in the way — done carefully.

## Before you start

- **Bugs:** open an issue with your macOS version, Mac model, the model you
  use, and the relevant lines from `~/Library/Logs/Sotto/sotto.log`
  (it never contains what you said).
- **Features:** open an issue first so we can agree on the shape. Things
  that fit: accuracy, latency, accessibility, languages, polish. Things that
  don't: accounts, cloud transcription, telemetry.

## Setup

```bash
brew install cmake          # whisper.cpp builds from source
npm run app:dev             # hot-reloading dev build
npm run ui:dev              # UI only, in a browser, with sample data
```

UI deep links in the browser preview: `/panel.html?view=languages`,
`/settings.html?tab=model` (general · model · language · about),
`/overlay.html`.

## Before you open a PR

```bash
npm run check   # TypeScript, cargo clippy -D warnings, unit tests
cargo fmt --manifest-path src-tauri/Cargo.toml
```

If you touched transcription, also run the end-to-end test described in the
README on a real model.

## Style

- Rust: `cargo fmt`, no clippy warnings, comments explain *why*.
- UI: the brand tokens in `ui/src/index.css` (ink, paper, one signal
  colour). Instrument Serif only for headings and the wordmark; IBM Plex
  Mono only for micro-labels and key caps.
- Copy: short, plain, second person. No exclamation marks.
- The logo, icon and banner are generated by `scripts/brand.py` — change
  them there, not in an image editor.
